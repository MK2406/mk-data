# mk-data

Campus data for the MK app. Every MK phone downloads `data.json` from here.

- **admin.html**: open it at `https://<your-user-name>.github.io/mk-data/admin.html` to send announcements and change dates, exams, subjects and the mess menu. Nothing goes live until you tap Publish.
- **data.json**: the data file. Don't edit it by hand unless you know JSON; use the admin page.
- **privacy.html**: the privacy policy link for the Play Store.

Rule: every published change must have a bigger `version` number. The admin page does this for you.
